THE LAST LIFE — TELEFONDAN DERLEME

Bu proje kaynak kodudur; doğrudan Minecraft mods klasörüne atılmaz.

1) GitHub hesabı açın/giriş yapın.
2) New repository ile boş bir depo oluşturun (ör. the-last-life). Public veya Private seçebilirsiniz.
3) Depoda Add file > Upload files ile bu klasörün İÇİNDEKİ dosya ve klasörleri yükleyin. En üstteki the_last_life klasörünün kendisini değil, içeriğini yükleyin. .github klasörünün de yüklendiğini kontrol edin.
4) Commit changes yapın.
5) Depoda Actions sekmesine girin. Build The Last Life iş akışı çalışır. İlk seferde birkaç dakika sürebilir.
6) İşlem yeşil tikle bittiyse çalıştırmaya tıklayın, sayfanın altındaki Artifacts bölümünden the-last-life-jar dosyasını indirin.
7) İnen artifact ZIP'ini açın. İçindeki the_last_life-0.1.0.jar dosyasını Mojo Launcher'ın kullandığı Minecraft 1.20.1 Forge profilinin mods klasörüne koyun.

DİKKAT: Derlemenin başarılı olması, modun oyunda tamamen test edildiği anlamına gelmez. Hata çıkarsa Actions sayfasındaki log gerekir. Bu ilk proje yalnızca gaz maskesi mekaniğinin başlangıç sürümüdür; bütün The Last Life içeriği değildir.
